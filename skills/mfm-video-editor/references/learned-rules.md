# Learned rules

Rules learned from the team's corrections. **These override `style-rules.md` when they conflict**, because each one comes from a real fix someone asked for.

How to add one (see SKILL.md, "Fix requests"):
- Write the rule so it applies to every future video, not just the one that was fixed.
- Always include **why**: the reason lets future edits apply the rule with judgment instead of blindly.
- Format: `- **Rule.** Why: reason. (YYYY-MM-DD, video-slug)`
- Group under a heading below. If a new rule contradicts an old one, replace the old one instead of keeping both.
