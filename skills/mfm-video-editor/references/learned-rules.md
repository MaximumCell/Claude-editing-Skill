# Learned rules

Rules learned from the team's corrections. **These override `style-rules.md` and `sfx-rules.md` when they conflict**, because each one comes from a real fix someone asked for.

How to add one (see SKILL.md, "Fix requests"):
- Write the rule so it applies to every future video, not just the one that was fixed.
- Always include **why**: the reason lets future edits apply the rule with judgment instead of blindly.
- Always keep **what the user actually said**, word for word. The rule is your reading of their note and could be wrong; keeping their words lets a bad reading be corrected later instead of hardening into a rule.
- Format: `- **Rule.** Why: reason. Said: "their exact words". (YYYY-MM-DD, video-slug)`
- File it under the right heading below.
- When a rule stops applying, **retire it instead of deleting it**: move it to "Retired" with the date and the reason, so the reversal stays visible.
